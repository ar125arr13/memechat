# فهرست ساده: چی الان روی سوپا بیسه و کجا باید بره

**وضعیت:** فقط فهرستبرداری. هیچچیزی جابهجا، پاک، یا تغییر نکرده. هیچ رمزی توش نیست.

> این فهرست از روی سورسهایای که قبلاً بهم دادی نوشته شده، نه از روی چیزی که امروز تو سایت
> زنده دیدم. یعنی «تو کد موجوده»، ولی «الان دقیقاً همینجوری رو سایت در حال اجراست» رو
> جداگانه چک نکردم. عدد مصرف واقعی هم نخوندم.

## چیهایی که «انبار» نیستن و یه جای کارکن میخوان

| چی الان هست | کجا باید بره | نکتهٔ مهم |
|---|---|---|
| ورود و رمز یکبارمصرف | جای کارکن جدید | اگه زود خاموش شه، کسی نمیتونه وارد شه |
| یادآوری «کی وارد شده» | جای کارکن جدید | نباید تو اپ نگه داشته بشه؛ یه نشونهٔ قفلشده کافیه |
| پیام خصوصی، گروهی، کانالی، جستجو، لیستها | جای کارکن جدید | حدود صد جور کار مختلف؛ هیچکدوم نباید حذف یا ساده بشه |
| نقشها (کاربر / ادمین / سوپر / مالک) | جای کارکن جدید | سپهر ادمینه، مالک نیست |
| تماس صوتی و تصویری | جای کارکن جدید | فقط تو گفتگوی خصوصیِ باز مجازه |
| استوری، پاسخها، پروفایل، پیام صوتی | جای کارکن جدید + فایلش تو انبارها | منطقشون سر جاش میمونه |
| صف انتظار و قانون «اول تأیید، بعد پاک کن» | جای کارکن جدید + بکاپ گیت هاب/گیت لب | تا سالم رسیدن چک نشه، هیچی پاک نمیشه |

## چیهایی که فایلان و میرن تو انبارها

| چی الان هست | کجا میره | چرا |
|---|---|---|
| عکس و فیلم و فایل پیامها (تا حدود ۱٫۸ مگ، بهصورت چسبیده به پیام) | R2 برای داغ و تازه، گوگل درایو برای آرشیو | الان هر بار که اپ چک میکنه، همراه پیام برمیگرده؛ همین بخش بیشترین حجم رو میبره |
| عکس پروفایل (کوچیک، چسبیده به پیام) | R2 (کش داغ) | دانلود تکراری کم شه |
| فایلهای قدیمی و کمسراغ | گوگل درایو (اصلی) + کپی یدک رو گیت هاب/گیت لب و گپ/روبیکا | آرشیو، نه چت زنده |
| تکتک قطعات و شناسنامهشون (شماره قطعه، محل، مهر سلامت) | جای کارکن + بکاپ گیت هاب/گیت لب | کمّتغییر؛ گیت هاب و گیت لب نباید دیتابیس چت زنده باشن |
| بکاپ کد و تنظیمات | گیت هاب + گیت لب | همین الانم همینجوره |
| فایلهایی که شبیه نقشهٔ جدولان (SQL) | گیت هاب + گیت لب | **فقط نقشهٔ جدولان، پشتیبان واقعی پیامها نیستن** |

## چیهایی که الان نمیدونم و نباید حدس بزنم

- گپ و روبیکا حداکثر چهقدر فایل نگه میدارن و تا کی نگهش میدارن (باید از کتابچهٔ
  خودشون خونده شه؛ تا اون موقع فقط کپی یدک کمحجم حساب میشن).
- دقیقاً چقدر حجم تو ماه رد و بدل میشه (پیشخوان مصرف خونده نشده).
- محتوای واقعی سایت زنده و بدنهٔ تابعی که الان اجرا میشه، جداگانه چک نشده.
- تعداد کاربرای همزمان.
