## نقشهٔ جریان (همون چیزی که خواستی)

| موقعیت | مسیر |
|---|---|
| پیام آنلاین | WebRTC، محتوا قبل از ارسال با Web Crypto رمز میشه |
| پیام آفلاین | صف تو دستگاه → ZIP فشرده + رمزشده، فقط بعد از تأیید مقصد علامت میخوره |
| تاریخچه | ZIP فشرده و رمزشده رو همان GitHub Pages |
| تاریخچهای که قبلاً گرفته شده | Cache مرورگر، با نسخه + هش؛ تغییر کرد → نسخهٔ تازه؛ خراب شد → نشون داده نمیشه |
| سیگنالینگ | همان `rt-post` / `rt-get` / `rt-clear` سوپا؛ فقط اطلاعات اتصال، بعد پاک میشه |
| پروفایل | فیلدهای عمومی از Pages؛ خصوصی و ورود همچنان سیستم فعلی |
| ورود | **دستنخورده و مستقل از WebRTC** |
| هر خطا | برگشت خودکار به مسیر فعلی؛ هیچ پیامی گم نمیشه |

## امنیت

- کلیدها تو دستگاه (Web Crypto؛ خود CryptoKey غیرقابل خروج، مادهٔ خام فقط تو
  IndexedDB همان دستگاه با عبارت بازیابی محافظت میشود) یا از طریق همان توکن ورود
  تحویل میشن؛ **هرگز** تو GitHub Pages، مخزن عمومی یا سورس کد نیستن. در حالت
  «نشست» سرور توان ریاضی باز کردن آرشیو را دارد = همان سطح اعتماد سیستم فعلی.
- سیگنالینگ فقط SDP / ICE / کلید عمومی موقت میبره؛ متن پیام، فایل، توکن و رمز
  ورود با `assertConnectionOnly` صریحاً ممنوع شدن (تست داره).
- نویسندهٔ سمتسرور متن خام، ایمیل، تلفن، هش رمز یا توکن رو پس میزنه؛ فایلهای
  نسخهدار قابل بازنویسی نیستن.
- صادقانه: WebRTC آیپی دستگاه رو کامل پنهان نمیکنه (خودت هم گفتی). هدف اینه که
  **محتوا** برای سرور سیگنالینگ و افراد غیرمجاز قابل خواندن نباشه، و این برقراره.
- صادقانه: برای وصل شدن پشت NAT، پیشفرض الان ۵ STUN رایگانه (بدون تغییر CSP، چون
  `connect-src` شامل WebRTC نمیشه). TURN واقعی نیاز به یه پُستچی داره؛ کدش کامله
  ولی **مستقر نشد** و رمزش فقط سمتسرور میمونه. اگه اونم نبود، مسیر آفلاین/فعلی
  جایگزینه. جزئیات `docs/STUN-TURN.md`.

## اجرا

```bash
cd mc-v2
npm test                                     # 21 tests passed
node migration/backup.mjs --fixture --out ./local-backup
node migration/export.mjs --backup ./local-backup --out ./local-out
node migration/verify.mjs --backup ./local-backup --out ./local-out
npm run decouple                              # گزارش جداسازی، بدون حذف
node migration/activate.mjs --out ./local-out
```

## محدودیتهایی که پنهان نکردیم

- GitHub Pages رایگانه: ۱ گیگ فضا، ۱۰۰ گیگ ترافیک نرم در ماه، ~۱۰ بیلد در ساعت.
  برای یه پیامرسان قدیمی، بستهها باید کوچیک و دستهای بمونن (همینجوری طراحی شده).
- Pages عمومیه: فقط متن رمزشده و پروفایل عمومی اونجا میره، هیچ اطلاعات خصوصی ای نه.
- `/api/v2` و `entry.v2.js` کامل نوشته شدن ولی **مستقر نشدن**؛ نوشتن روی Pages
  نیاز به `GITHUB_TOKEN`، و TURN نیاز به `MC_V2_TURN_*` سمتسرور و اجازهٔ صاحب
  پروژه داره. تا اون موقع `iceMode:"server"` خودکار به STUN رایگان برمیگرده.
- ساختار ۴۴ جدول زنده فقط از روی `information_schema` تأیید شد؛ **بکاپ واقعی
  ردیفها گرفته نشد** چون کپی کردن دادهٔ حساس کاربران تو workspace خطرناک است.
  اسکریپت `migration/backup.mjs` برای اجرای امن تو محیط صاحب پروژه آماده است.
- سوپا بیس همچنان زندهست. `decouple:true` تو **کد** مرز داده رو جدا میکنه و
  `migration/decouple.mjs` گزارش «صفر حذف» مینویسه، ولی **سوپای زنده خاموش نشد**:
  ورود، سیگنالینگ و پشتیبان سر جان. هدف اینه که **محل اصلی تاریخچه** نباشه، نه
  اینکه یهو خاموش بشه. خاموش کردنش آخرین قدمه، بعد از بکاپ واقعی و تست.
