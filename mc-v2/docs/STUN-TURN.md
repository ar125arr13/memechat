# STUN / TURN — به زبان ساده

> **آینه و پُستچی.** دو گوشی پشت اینترنت همدیگه رو نمیشناسن. «آینه» (STUN) به هر کدوم
> میگه «از بیرون اینجوری دیده میشی»؛ اگه باز هم نتونستن مستقیم وصل شن، «پُستچی»
> (TURN) بسته رو از یکی میگیره به اون یکی میرسونه. پُستچی **محتوا رو نمیخونه**،
> چون بستهها قبلش رمز شدن و خود WebRTC هم رمزگذاری داره.

## چی انجام شد (بدون دست زدن به سایت زنده)

| قبل | الان |
|---|---|
| `iceServers: []` → فقط شبکهٔ محلی وصل میشد | پیشفرض ۵ «آینه» رایگان و بدون رمز وصل شد |
| اگه TURN میخواستی، باید تو کد عمومی مینوشتی | رمز TURN فقط از `/api/v2?action=ice` سمتسرور میاد |
| هیچ محافظتی در برابر رمز لو رفته نبود | هر `credential` تو تنظیمات عمومی صریحاً رد میشه |
| اگه سرور TURN خراب بود، اتصال میشکست | خودکار برمیگرده به همان ۵ آینه، بعد مسیر قدیمی |

فایل جدید `src/ice.js` این کارو میکنه؛ `rtc.js` و `boot.js` ازش استفاده میکنن.
**هیچ Edge Functionـی مستقر نشد، هیچ secretـی ساخته نشد، CSP و `MC_API` عوض نشدن.**

## چرا CSP نیازی به تغییر نداشت

CSP فعلی `connect-src 'self' https://…supabase.co` فقط رفتوآمدهایی مثل
`fetch`، `XMLHttpRequest`، `WebSocket` و `EventSource` رو محدود میکنه؛
`RTCPeerConnection` تو فهرستش نیست
([MDN](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy/connect-src)،
[بحث W3C](https://lists.w3.org/Archives/Public/public-webrtc/2018Jan/0072.html)،
[نمونهٔ مرورگرها](https://github.com/jcosta33/sourdaw/issues/2179)).
یعنی اضافه کردن آدرس STUN/TURN **نیازی به باز کردن `connect-src` نداره**.
یه دستور پیشنهادی `webrtc` تو CSP3 هست ولی تو مرورگرهای معمولی هنوز اعمال نمیشه؛
برای همین ما کاری نکردیم که بعداً تو مرورگر تازهای غافلگیر بشه. البته این یعنی
مرورگر اجازهٔ خروج ترافیک ICE میده — دقیقاً همان چیزی که برای تماس/پیام زنده لازمه،
و خودت هم گفته بودی آیپی دستگاه از صاحب دستگاه پنهان نمیشه.

> نکتهٔ امنیتی صادقانه: چون `connect-src` جلوی ICE رو نمیگیره، لیست سرورها رو
> تو کد **سفید/محدود** کردیم (`normalizeIceServers`) و اجازه نمیدیم آدرس عجیب،
> `javascript:` یا رمز عمومی واردش بشه.

## آینههای رایگانی که گذاشتیم

```
stun:stun.l.google.com:19302
stun:stun1.l.google.com:19302
stun:stun.cloudflare.com:3478
stun:stun.services.mozilla.com
stun:openrelay.metered.ca:80
```

چندتا گذاشتیم که اگه یکی تو شبکهٔ کاربر بسته بود، بقیه امتحان شن. هیچکدوم
رمز یا حساب نمیخوان، هیچ سرویس پولی/کارتی اضافه نشد
([فهرست عمومی STUN](https://liveapi.com/blog/stun-server/)).

## پُستچی (TURN) — اختیاری، فقط با اجازهٔ تو

آینهٔ تنها برای بعضی NATها و شبکهایی که UDP رو میبندن کافی نیست. اونجا TURN لازمه،
معمولاً روی پورت ۴۴۳ و TCP/TLS تا از فایروال رد بشه. گزینهٔ رایگان و بیکارت
[Open Relay Project](https://www.metered.ca/tools/openrelay/) ئه (۲۰ گیگ ترافیک
ماهانهٔ رایگان، پورت ۸۰/۴۴۳، بدون کارت؛ الان برای گرفتن کلید نیاز به یه حساب
رایگان داره). **ما حسابی نساختیم، کلیدی نگرفتیم، و از تو هم تو چت کلید نخواستیم.**

اگه روزی خواستی وصلش کنی، فقط تو محیط امن صاحب پروژه (Supabase Secrets) یکی از
این دوتا شکل رو بذار؛ مقدارش هرگز تو مخزن، Pages یا چت نباشه:

```
MC_V2_TURN_URLS=turn:relay.example:443?transport=tcp,turns:relay.example:5349
MC_V2_TURN_USERNAME=...
MC_V2_TURN_CREDENTIAL=...
```

یا یهجا:

```
MC_V2_ICE_SERVERS_JSON=[{"urls":"turn:relay.example:443?transport=tcp","username":"...","credential":"..."}]
```

بعد `MC_V2_CONFIG.iceMode = "server"` میشه و مرورگر با **همان توکن ورود فعلی**
از `/api/v2?action=ice` لیست رو میگیره. تا وقتی اون مسیر مستقر نشده، کد خودکار
به همان ۵ آینه برمیگرده؛ پیام گم نمیشه. رمز تو پاسخ سرور هست، ولی تو لاگها
`***` نشون داده میشه و هرگز وارد سیگنالینگ/ Pages نمیشه.

## تنظیمات قابلاستفاده (همه اختیاری)

| گزینه | پیشفرض | معنی |
|---|---|---|
| `iceMode` | `stun` | `off` / `stun` / `custom` / `server` / `function` |
| `iceServers` | `null` | فقط آرایهٔ **بدون رمز**؛ اگه `credential` بذاری خطا میده |
| `iceProvider` | `null` | تابع async خودت، باز هم بدون رمز عمومی |
| `iceTransportPolicy` | `all` | `relay` یعنی حتماً از TURN رد شود |
| `iceCacheTtlMs` | `300000` | لیست سرور ۵ دقیقه کش میشه، هر بار درخواست نمیره |

مثال امن (بدون هیچ رمزی تو صفحه):

```html
<script>
window.MC_V2_CONFIG = { mode: "mirror", iceMode: "stun", iceTransportPolicy: "all" };
</script>
<script src="./mc-v2/boot-inline.js"></script>
```

## چی هنوز انجام نشده

- استقرار `/api/v2` و تنظیم Secretهای TURN → نیاز به اجازهٔ صاحب پروژه.
- ساخت حساب رایگان Open Relay / گرفتن API key → ما نکردیم، تو چت هم نخواستیم.
- تست دو گوشی واقعی پشت اینترنت → بدون کاربر واقعی انجام نشد.
- تغییر CSP، لینک، ظاهر، ورود، `MC_API` یا پاک کردن هر دادهٔ قدیمی → **هیچکدوم نشد.**

تستهای خودکار (۲۰ تا) الان ثابت میکنن: آدرس بد رد میشه، رمز عمومی رد میشه،
رمز تو لاگ `***` میشه، سرور TURN خراب → STUN میمونه، و مسیر `/api/v2?action=ice`
بدون ورود ۴۰۱ میده.
