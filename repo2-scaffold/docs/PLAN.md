## چرا «انتقال به ریپوی دوم» دیگه معنی ندارد
طرح قدیمی میخواست بلابها را به یک مخزن خصوصی GitHub ببرد و بعد ردیفهای
outbox را پاک کند. دو مشکل داشت:
1. صاحب پروژه گفت مقصد دوم دیگر روی سرویس قبلی نباشد.
2. صاحب پروژه گفت **هیچ دادهای حذف یا ریست نشود**؛ همان `DELETE` قدیمی منتفی شد.

## چرا روبیکا «دیتابیس» نمیشود (بدون API رسمی)
روبیکا پیامرسان است. بدون API رسمی:
- نمیتوان از سرور خودکار توی آن نوشت؛
- نمیتوان کوئری/تراکنش/ایندکس/خواندن لحظهای داشت؛
- نمیتوان تحویل را خودکار تأیید کرد؛
- مهندسی معکوس پروتکل خصوصی شکننده و نقض ToS است → انجام نشد.

**راه واقعاً قابل اجرا:** کوریر دستی. بستههای متنی رمزشده `MCPK1` ساخته میشوند،
انسان آنها را توی حساب شخصی خودش در روبیکا کپی میکند، و برگشت با تأیید
SHA-256 موبهمو است. روبیکا فقط ciphertext میبیند.
